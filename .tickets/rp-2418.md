# Extend caption fallback across table continuation pages

Intent: fix Docling LLM bitmap coverage when a captioned table is missed as a structured TableItem and spans onto continuation pages. Current caption fallback crops only the caption page from the caption to page bottom, e.g. P174008 Table 6 page 20, leaving continuation pages 21-22 unrepresented unless Docling independently detects them. Technical goal: add deterministic continuation-page bitmap fallbacks for captioned tables using nearby page text/layout signals, without introducing GPU/VLM dependence or excessive full-page bitmaps.

## Acceptance Criteria

For P174008/Table 6, a focused run or artifact inspection shows fallback table bitmap records for the caption page and continuation pages 21-22. LLM Markdown/HTML include the continuation bitmap references in page order. The continuation logic has targeted unit tests and does not create continuations when the next page has an explicit new table caption or existing table item. Ruff and targeted pytest pass.


## Notes

**2026-06-18T17:01:42Z**

Implemented caption-fallback continuation handling. After a missed captioned table fallback is created, the wrapper now scans immediately following pages (bounded by CAPTION_FALLBACK_MAX_CONTINUATION_PAGES) and adds page-width continuation fallback bitmaps when text/layout signals look like a table continuation. It stops at an existing Docling TableItem page, a new table caption, a new major section heading at page start, or a non-continuation page. LLM Markdown/HTML insert continuation images at the first text anchor on each continuation page and bitmap exclusion zones suppress duplicate OCR/text. Focused P174008 pages 20-25 run at tmp/docling-convert/p174008-table6-continuation-smoke produced fallback_table_bitmaps for pages 20,21,22,23,24 plus the existing Docling table bitmap on page 25; LLM markdown/html contain five fallback refs in order and zero <p> wrappers. Visual check of continuation crops page 21 and page 24 confirmed the table body is retained. Verification: ruff passed and targeted pytest passed (33 tests).
