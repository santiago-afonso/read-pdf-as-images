# Render LLM Markdown/HTML with simple tables as HTML and complex tables/figures as bitmaps

Intent: produce the requested final representation: simple tables are emitted as HTML tables inside Markdown/HTML; complex tables, diagrams, figures, and likely bitmap tables are externally referenced bitmaps. Scope: add an LLM-oriented export alongside raw Docling exports, using complexity decisions from the scoring ticket; support referenced images by default and optional embedded outputs; include compact diagnostics/provenance. Non-goals: exact layout reproduction or base64-by-default output.

## Acceptance Criteria

Given a conversion with simple and complex tables, the LLM Markdown contains HTML table markup for simple tables and image references for complex tables/figures; the HTML output references the same external images; manifests explain each render decision. P174008 pages 33-35 produce bitmap references for the policy-matrix tables rather than relying only on structured Markdown tables.
