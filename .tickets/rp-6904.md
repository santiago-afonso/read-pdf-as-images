# Lean LLM exports and safer picture/icon policy

Intent: implement user-requested output-policy changes after the crop review. Scope: discard icons/page furniture from LLM outputs using deterministic bitmap geometry/caption heuristics rather than verbose classifier output; make semantic figures use safer page-render crops analogous to complex tables when Docling's picture crop may be too tight; remove classifier/Meta diagnostics from LLM-facing HTML/Markdown captions/comments; and make generated LLM HTML leaner and close to Markdown by stripping styling/classes/data attributes that have no semantic role. Non-goals: removing sidecar manifests/diagnostics, changing raw Docling exports, or perfect semantic figure detection.

## Acceptance Criteria

LLM Markdown/HTML omit tiny icons and page-furniture images; semantic figure output references an expanded/page-width source-page crop when provenance is available; LLM HTML has minimal tags with no CSS/classes/data diagnostic metadata; tests cover icon rejection, picture crop preference, and lean HTML behavior; figure and P174008 smokes still work.
